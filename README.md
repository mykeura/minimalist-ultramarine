# Minimalist Ultramarine

A minimal Chrome theme in a light, calm palette, by Miguel Euraque.

A soft periwinkle frame, a pale blue toolbar and new tab page, and cool gray text. It is a light, calm ultramarine, blue with a hint of violet.

![Minimalist Ultramarine Theme Preview](images/preview.png)

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)

## Features

- **Palette:** periwinkle frame, pale blue surfaces, cool gray text
- **Minimalist design:** clean and uncluttered
- **Easy installation:** Chrome Manifest V3
- **Gentle on the eyes:** low-contrast colors that stay easy to read

## Installation

### From source

1. Clone this repository.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click **Load unpacked** and select the theme folder.
